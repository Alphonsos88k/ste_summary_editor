Character Codex — Guide

What is Character Codex?

Character Codex generates a structured character biography for any SillyTavern character card and renders them as a stylised 3D voxel avatar.

  • Select a character on the left page (auto-detected from active chat, or choose from the dropdown).
  • Optionally tick Supplementary files or Summary entries to include more context.
  • Click Generate Codex to produce all biography sections in one API call.
  • The right page shows the TOC — click any section dot or use the ← → arrows to navigate.

Context note: Regen uses only the character card + ticked sources. SillyTavern lorebooks/world info are not included unless they have been imported as supplementary files.

Biography Sections

  • Introduction & Highlights — quick-reference summary.
  • Personality — traits, quirks, motivations.
  • Appearance & Quirks — physical description, style, notable features.
  • Relationship with User — how they relate to the player/user character.
  • NSFW Traits and Intimate Dynamic — hidden behind blur until revealed.
  • Their World — setting, factions, backstory context.

Each section is independent — regen one without touching the others. Custom sections can be added from the TOC page.

Panel Header Buttons

  • ? — Opens this guide (click again to close).
  • ⚙ — Opens the Settings popup. Configure default tier and all API output token budgets.
  • ⛶ — Toggle fullscreen mode for the Codex panel.
  • × — Close the Codex panel.

Section Page Buttons

  • ✎ pencil — Toggle the section textarea between read-only and editable. Use this to manually write or paste content without calling the LLM.
  • ↻ circle (header) — Regenerate this section using the character context. Same as the Regen button below the text.
  • Feedback for regen… — Type a note here before clicking Regen to guide the rewrite (e.g. "make it more emotional" or "focus on her rivalry with X").
  • ↻ Regen — Regenerate the current section, incorporating any feedback. Token budget set in ⚙ Settings → Section regen tokens.
  • System Prompt — Expandable — shows the AI instruction used for this section's regen. Edit it to permanently customise the writing style for that section.

TOC Page Buttons

  • + Add — Opens a form to create a custom section. Type a name (e.g. "Combat Style") and the AI generates its content automatically.
  • 💬 Suggest — Asks the AI to suggest a new section that's missing from the current codex, then generates it.
  • ⬇ Export ZIP — Downloads all sections as a .zip of plain-text .txt files.

Voxel Control Buttons

  • ◉ Front — Reset camera to front-facing view.
  • ⟳ Spin — Toggle auto-rotation (turns green when active).
  • ✦ Generate Voxel — Send the Voxel Description to the LLM and render the result.
  • ⚡ Quick Gen — Auto-fill the Voxel Description from Appearance & Personality sections (requires both to be generated first).
  • ⊙ Fit — Zoom out to show the full character.
  • Drag / Scroll — Rotate and zoom the canvas manually.

Generating a Voxel Avatar

The voxel renderer builds a stylised 3D character (indie game / voxel ARPG aesthetic) from a JSON spec the LLM produces.

  1. Type a plain-text appearance description in the Voxel Description textarea — or paste a character quote directly.
  2. Click ✦ Generate Voxel — the LLM interprets your description and returns a spec, which renders immediately.
  3. Adjust the Quality tier and click Generate Voxel again to re-render at that level.

A Codex biography is not required — a plain description is enough. For best results, mention build, fur/skin colour, outfit colours, and any accessories.

Token Settings (⚙)

All LLM output budgets are configurable in the ⚙ Settings popup:

  • Voxel spec tokens — output budget for ✦ Generate Voxel (default 900). Increase if specs get cut off for complex characters with many accessories.
  • Quick gen tokens — output budget for ⚡ Quick Gen (default 300). 300 is usually plenty for a 2–5 sentence description.
  • Section regen tokens — output budget for per-section ↻ Regen (default 800). Increase for sections that feel truncated.

Higher values allow longer LLM responses but use more API tokens and cost more.

Non-token settings: Stage tone — override the render's backdrop mood (Auto follows the character's lighting; bright pastel studios or dark stages). Camera angle — the default view on open/reset: Hero 3/4 low angle, straight on, or quarter.

Min — Minecraft Style

All tiers render the full body: head, hair, face (eyes + nose), arms, legs, shoes. Anthro characters always get ears and muzzle.

Min is a clean Minecraft-biped with:

  • Idle animation — breathing bob + arm/leg swing so limbs don't look fused.
  • Composed face: sclera + iris + pupil, eyebrows, mouth; anthro get tapered top ears + two-part muzzle with nose tip.
  • Belly zone, shirt hem line, two-tone hand/paw tips — low voxel count, full character.
  • Up to 2 accessories.
  • Grid floor only, no backdrop. No tattoos, custom parts, or shirt patterns.

Med — More Detail

  • Shirt sleeves and collar visible on arms.
  • Colour zones applied — belly fur strip, face mask, inner ears for anthro.
  • Up to 4 accessories; up to 2 tattoos (arm / chest / back).
  • Backdrop scenes: forest, castle, cave, clouds, plus free-text (city, fire, ice…).
  • Up to 12 custom-part boxes.

High — Full Detail

  • Shirt cuffs + belt overlay added on top of sleeves and collar.
  • All colour zones active.
  • Up to 6 accessories; tattoos on any location.
  • All named backdrop scenes (lake, dungeon) + free-text fully rendered.
  • Up to 24 custom-part boxes — tentacles, extra heads, non-standard limbs.
  • Ground scenes on raised voxel pedestal; sky-only backdrops (clouds, void) skip it.

Templates & Body Types

  • humanoid — standard biped, no head modifications.
  • anthro_biped — biped with animal muzzle/snout and side ears. Use for furries, beastkin, kemonomimi, any two-legged creature with animal head features.
  • robot / monster — same frame as humanoid (future: heavier proportions).

Builds: slim, medium, stocky, tall, short.

Hair styles: short, long, bun, spiky, bald. For anthro this sets the fur cap/crest colour.

Accessories

Up to 6 at high tier. Types and locations:

  • Head: hat, crown, halo, glasses, horns (curved — demons/bulls), antlers (palmate — deer/reindeer/moose)
  • Body: scarf, necklace, cape, armor_chest, wings, shoulder_pad
  • Lower: belt, tail (size-aware: small = bob, medium = fluffy, large = bushy), gloves

Hooves: set shoes to a very dark brown (#1a0a04). Paws: match shoes to fur/skin colour.

Anthro Colour Zones

For anthro_biped, three optional zones override defaults:

  • belly — lighter fur strip on torso front. Keep lighter than shirt so the stripe shows.
  • face_mask — muzzle/snout colour (default: darkened skin).
  • ear_inner — inner ear pad colour (default: lightened hair).

Describe these in the voxel textarea: "cream belly, dark orange face mask, pink inner ears".

Lighting & Backdrops

Moods render as stages: standard (bright cream studio), warm (bright amber), cool (bright sky-blue), dramatic (dark spotlight + blue rim), eerie (dark green glow). Bright stages show a soft contact shadow under the character; dark stages show a glow pool and grid. Override any time via ⚙ Settings → Stage tone.

Backdrop takes 0–2 elements. Named scenes: castle, forest, lake, cave, dungeon, clouds.

Free-text keyword-matched: city/neon/urban → dark concrete + amber windows; fire/lava → red; ice/arctic → pale blue; magic/arcane → purple.

Ground scenes render on a raised voxel plate. Sky-only (clouds, void, shadow) skip the plate.
