Node Editor — Guide

Chat File Node

Represents a single .jsonl chat file from the character's chat history.

  • Add it with + in the Files sidebar.
  • Single-file lock — only one chat file can be on the canvas at a time. All other + buttons dim until the current file node is removed.
  • Remove it with the sidebar × button or by right-clicking the node → Remove.

The file name is shown inside the node body and truncated with … if too long.

Entry Node

Represents one numbered summary entry from the Review table.

  • Add it with + in the Entries sidebar. Multiple entries can be on canvas simultaneously.
  • The entry number is the node title; a snippet of the content is shown in the body.
  • Entries update automatically when you ingest new files or delete an entry in the Review tab.

Ports

Ports are the small circles on the edges of each node.

  • Output ports are on the right side; input ports on the left.
  • Chat File — one output: chats — sends the file reference downstream.
  • Entry — one input: from — receives from a Chat File or another Entry's ref port.
  • Entry — one output: ref — passes context forward; connect it to another Entry's from to chain entries.

Connection Rules

  • One Chat File at a time — only one Chat File node can be on the canvas. Its chats output can connect to any number of Entry nodes.
  • Entry chaining — an Entry's ref output can connect to another Entry's from input, expressing that two entries are related or sequential.
  • Multiple parents — an Entry can receive from both a Chat File and another Entry simultaneously, modelling shared context.
  • Links are colour-coded per connection for easy tracing.

Connecting & Disconnecting

  • Connect — hover over an output port until it highlights, then drag to an input port on another node and release.
  • Disconnect — right-click the link line → Delete, or right-click the node → Remove to drop the node and all its links.

Navigation

  • Pan — click and drag on empty canvas space.
  • Zoom — scroll wheel anywhere on the canvas.
  • Zoom pill (bottom-right) — click + or − to step zoom. Click the % label to reset to 100%.
  • Move node — drag the node's title bar.
  • Context menu — right-click a node for Remove, Clone, and other actions.

Toolbar Actions

Buttons are grouped by what they affect. View buttons only move the camera — nodes stay where they are. Arrange buttons physically reposition nodes on the canvas.

VIEW

  • Fit — zoom and pan the camera to fit all nodes inside the visible canvas area. Nodes are not moved.
  • Origin — reset the camera to canvas origin (0, 0) at 100% zoom. Nodes are not moved.

ARRANGE

  • Gather — snap all scattered nodes into a compact two-column grid (files left, entries right), then fit.
  • Layout — arrange nodes into a uniform vertical grid then fit. Good starting point for a clean manual layout.
  • Snake — arrange entries in a zigzag sweep across the canvas (left-to-right on odd rows, right-to-left on even rows). Keeps large entry sets compact and within the viewport without a long vertical scroll.
  • Line — place all nodes in a single horizontal line sorted by entry number, with file nodes anchoring the left. Good for seeing the full sequence at a glance.

OTHER

  • Clear — remove every node and connection from the canvas. Does not delete files or entries.
  • ▶ Run — execute the 3-prompt analysis pipeline on all connected nodes. Greyed out until a connection exists. See the Analysis section for details.
  • ? — open this help booklet.
  • ⚙ Prompts — edit the system prompts used by the analysis pipeline.

Hover any button for a brief tooltip describing its action.

Sidebar Pop-out Panels

Both the Files and Entries sections in the left sidebar have a ⧉ pop-out button in their header.

  • Clicking it detaches that list into a floating draggable panel so you can reposition it freely while working on the canvas.
  • Close the floating panel with its × button to re-dock it.
  • Both panels can be popped out simultaneously.

LLM Prompts

Click ⚙ Prompts in the toolbar to open the prompt editor. Three prompts power the analysis pipeline:

  • Chat Digest — Pass 1 — generates a digest from the raw chat file.
  • Chat Digest Refinement — optional feedback loop to refine the digest (up to 3 rounds).
  • Entry Analysis — Pass 2 — analyses entries against the digest. Should return structured JSON with REWRITE / SPLIT / MERGE / NO_CHANGE actions.

Changes save immediately. Prompts are also accessible from the main Prompts Hub.

Running the Analysis

The ▶ Run button in the toolbar executes the full 3-prompt pipeline against all nodes connected on the canvas.

  • The button is greyed out until at least one connection exists between a Chat File node and an Entry node.
  • Clicking ▶ Run opens a confirmation dialog listing the file and entries that will be analysed, and the passes that will run.
  • Click Run in the dialog to start. The button label shows live progress (Pass 1…, Refine 1/3…, Entry #N…).
  • When complete, a Results dialog shows the generated digest and per-entry analysis output.

Pass 1 — Chat Digest

The Chat Digest prompt is sent first.

  • The full chat file is loaded and formatted as a readable transcript.
  • The prompt + transcript is sent to the LLM, which returns a structured digest — a condensed account of events, tone, and key details.
  • This digest is the shared context for all subsequent passes.

Refinement (optional)

If the Digest Refinement prompt is set, the digest is fed back to the LLM in a feedback loop — up to 3 rounds — each round replacing the previous digest with an improved version. The loop stops early if the output stops changing.

Leave this prompt empty to skip refinement entirely.

Pass 2 — Entry Analysis

The Entry Analysis prompt is run once per connected entry, in graph order (following ref chains depth-first).

  • Each call receives the digest from Pass 1 and the entry content as the user message.
  • The prompt should instruct the LLM to return structured JSON with a recommended action and a reason, for example:

{ "action": "REWRITE", "reason": "Entry contradicts digest — character was not present." }

Valid actions: REWRITE · SPLIT · MERGE · NO_CHANGE.

Results are displayed in the Results dialog under each entry number. Edit prompts via ⚙ Prompts in the toolbar.
