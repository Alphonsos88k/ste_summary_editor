ℹ Node Editor — Guide

Nodes

  • Chat File node — represents one .jsonl chat file. Add it by clicking + next to a file in the Files sidebar. Only one chat file can be on the canvas at a time (single-file lock).
  • Entry node — represents one summary entry from the Review table. Add it by clicking + in the Entries sidebar. Multiple entries can be on the canvas simultaneously.

Ports & Connections

  • Each node exposes circular ports on its edges. Output ports (right side) send data; Input ports (left side) receive it.
  • Chat File has one output port chats (green) — drag from it to an Entry's input to link them.
  • Entry has one input port from (cyan) and one output port ref — the output can chain to future analysis nodes.
  • Drag from any output port circle to any compatible input port circle to create a connection. Connections are colour-coded per chat file.
  • To remove a connection: right-click the link line, or right-click the node and choose Remove.

Canvas Navigation

  • Pan — click and drag on empty canvas space.
  • Zoom — scroll wheel, or use the + / − zoom pill (bottom-right). Click the % label to reset to 100%.
  • Right-click a node for context actions (Remove, Clone, etc.).

Toolbar

  • Fit — zoom and pan to fit all nodes in the visible area.
  • Origin — reset view to canvas origin (0, 0) at 100% zoom.
  • Gather — snap all scattered nodes back to a tidy grid near the centre.
  • Layout — auto-arrange all nodes into a grid, then fit to view.
  • Clear — remove every node and connection from the canvas.
  • ⚙ Prompts — edit the LLM system prompts used for digest generation (Pass 1) and entry analysis (Pass 2).

Pop-out Panels

  • The Files and Entries sidebar sections each have a ⧉ pop-out button — click it to detach that list into a draggable floating panel so you can reposition it freely while working on the canvas.
